# About sitey

A free subdomain, without buying a domain first.

Take a name like `myapp.sitey.my` and point it at whatever you have built.

## What it does

- **Issues names** under `sitey.my` · `sitey.one` · `officials.my` · `officials.one`
- **A and CNAME records** — send the name to your server or host
- **TXT records** — add the ownership value a host such as Vercel asks for
- **Web and API** — click it in a browser, or call it from code
- **Agents use it too** — an MCP server, so an AI agent can claim a name itself

## What it does not do

- **It does not sell domains.** Subdomains are lent, not sold
- **It does not host anything.** Put your site wherever you like and take only the address from here
- **No apex domains.** `sitey.my` itself is not on offer

## How to use it

1. Search for the name you want. No account needed
2. Choose where it points, and create it
3. If your host asks for an ownership check, add the TXT value it gives you

The target **does not have to be serving yet.** Claim the name first and deploy to it later.

The walkthroughs are in the [docs](/docs) and on the [blog](/blog).

## A name is lent, not given

A name nobody uses is a name nobody else can have, so each one carries a term.

- Created under an account — **3 months**
- Created without one — **1 month**

A notice goes out before it expires, and one button extends it. A name is never removed for being unreachable; you are only told.

## Is it free

Yes — **five names per account**. If you need more, get in touch.
