# sitey 소개

도메인을 사지 않고도 주소를 하나 가질 수 있게 해주는 서비스입니다.

`myapp.sitey.my` 같은 이름을 무료로 받아서, 만든 사이트에 붙일 수 있어요.

## 무엇을 하나

- **주소 발급** — `sitey.my` · `sitey.one` · `officials.my` · `officials.one` 아래에 원하는 이름을 만듭니다
- **A · CNAME 레코드** — 만든 주소를 원하는 서버나 호스팅으로 보냅니다
- **TXT 레코드** — Vercel 같은 호스팅이 요구하는 소유 확인 값을 넣습니다
- **웹과 API 둘 다** — 브라우저에서 눌러도 되고, 코드에서 불러도 됩니다
- **AI 에이전트도 씁니다** — MCP를 지원해서 에이전트가 직접 주소를 만들 수 있어요

## 무엇을 하지 않나

- **도메인을 팔지 않습니다.** 서브도메인만 빌려드립니다
- **호스팅을 하지 않습니다.** 사이트는 다른 곳에 올리시고 주소만 여기서 가져가세요
- **apex 도메인은 발급하지 않습니다.** `sitey.my` 자체는 대상이 아니에요

## 어떻게 쓰나

1. 원하는 이름을 검색합니다. 로그인 없이도 됩니다
2. 어디를 가리킬지 정해서 만듭니다
3. 호스팅이 소유 확인을 요구하면 TXT 값을 넣습니다

가리키는 곳이 **아직 살아 있지 않아도 만들 수 있습니다.** 이름을 먼저 잡아두고 나중에 배포하셔도 돼요.

자세한 절차는 [문서](/docs)와 [블로그](/blog)에 있습니다.

## 이름은 빌려드리는 것입니다

쓰지 않는 이름이 묶여 있으면 다른 사람이 못 씁니다. 그래서 기간을 둡니다.

- 계정으로 만든 주소 — **3개월**
- 계정 없이 만든 주소 — **1개월**

만료 전에 안내 메일을 보내드리고, 버튼 한 번이면 기간이 늘어납니다. 주소가 잠깐 안 열린다고 지우지는 않아요. 알려드리기만 합니다.
