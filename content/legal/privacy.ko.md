# 개인정보처리방침

시행일 2026-09-14 · 운영 sitey (sitey.my)

## 1. 수집하는 항목

**구글 계정으로 로그인할 때**

- 이메일 주소
- 구글 계정 식별자
- 이름, 프로필 사진 주소
- 가입 시각

**주소를 만들 때**

- 만든 서브도메인 이름, 어느 루트 도메인인지
- 가리키는 값 (A 레코드의 IP, CNAME의 호스트명, TXT의 값)
- 만든 시각, 만료 시각
- **계정 없이 만든 경우 — 소유 토큰의 되돌릴 수 없는 해시.** 토큰 자체는 만들 때 한 번 돌려주고 저장하지 않습니다. 이 해시가 어느 곳에서 접속하든 그 주소가 본인 것임을 증명합니다
- **계정 없이 만든 경우 — 만든 사람의 IP 주소.** 이제 이것만으로 소유자를 가리지 않습니다(토큰이 그 일을 합니다). 한 주소에서 몇 개를 만들었는지 세는 데 쓰고, 소유 토큰이 생기기 전에 만든 주소는 여전히 이것으로 가립니다. 계정으로 만든 주소에는 저장하지 않습니다

**API 키를 발급받을 때**

- 키의 해시값과 앞 몇 글자. 원본 키는 저장하지 않습니다
- 발급 시각, 마지막 사용 시각

**로그인 상태 유지**

- 세션 식별자, 발급·만료 시각
- IP나 브라우저 정보는 세션에 저장하지 않습니다

**서비스 이용 기록 (서버 로그)**

- 요청 시각, 요청 방식, 요청한 화면의 경로 형태, 응답 코드, 처리 시간
- 요청한 주체 — 계정 또는 익명 식별자
- **IP 주소는 원본이 아니라 되돌릴 수 없는 해시로** 기록합니다
- 검색하거나 시도한 서브도메인 이름은 로그에 남기지 않습니다

**메일 발송 기록**

- 언제 어떤 종류의 메일을 보냈는지, 수신 주소의 해시

## 2. 이용 목적

| 항목 | 목적 |
| --- | --- |
| 이메일, 구글 식별자 | 본인 확인, 로그인 |
| 이름, 프로필 사진 | 화면 표시 |
| 서브도메인 기록 | DNS 서비스 제공 |
| IP (계정 없는 주소) | 소유자 확인, 어뷰징 방지 |
| API 키 해시 | 인증 |
| 서버 로그 | 장애 대응, 어뷰징 방지, 서비스 개선 |
| 이메일 주소 | 만료 안내 발송 |

## 3. 보유 기간

- **계정 정보** — 탈퇴 요청 시 지체 없이 파기합니다
- **서브도메인 기록** — 해당 주소가 삭제되거나 만료되어 회수될 때까지
- **API 키** — 삭제 요청 시까지
- **세션** — 만료 시각이 지나면 무효가 되며, 주기적으로 삭제합니다
- **서버 로그** — 장애 대응과 어뷰징 판단에 필요한 기간 동안 보관하며, 오래된 것부터 순차적으로 삭제합니다
- 법령이 보관을 요구하는 경우 그 기간을 따릅니다

## 6. 쿠키

**로그인 쿠키 (필수)**

로그인 상태를 유지하는 데만 사용합니다. 브라우저 스크립트가 읽을 수 없도록 설정되어 있고, 이 사이트 밖으로 전송되지 않습니다. 브라우저에서 쿠키를 차단하시면 로그인할 수 없습니다.

**광고 쿠키 (구글 애드센스)**

이 사이트는 구글 애드센스를 사용합니다. 구글을 포함한 제3자 공급업체가 쿠키를 사용하여 사용자의 이전 방문 기록을 바탕으로 광고를 게재할 수 있습니다.

- 구글의 광고 쿠키 사용 방식: `google.com/policies/technologies/ads`
- 맞춤 광고를 원하지 않으시면 `adssettings.google.com` 에서 끄실 수 있습니다
- 제3자 공급업체의 쿠키는 `aboutads.info` 에서도 차단하실 수 있습니다
