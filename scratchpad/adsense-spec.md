# 작업 — 애드센스 로더 스크립트를 `<head>` 에 넣는다

2026-09-14. 지시자: 자비스. **배포하지 마라 · 원격에 올리지 마라.** 로컬 커밋까지만.

## 무엇을

Jay 가 애드센스에서 받은 스니펫이다. **이것만** 넣는다.

```html
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-4214732111289465"
     crossorigin="anonymous"></script>
```

**목적은 「사이트 소유 확인 + 심사 신청」이다. 광고를 띄우는 것이 아니다.**

## 🔴 하지 말 것 — 여기가 핵심이다

- **광고 단위(`<ins class="adsbygoogle">`)를 만들지 마라.** 화면에 광고가 나오면 안 된다. 지금은 **승인만** 받는다
- **`ads.txt` 를 만들지 마라.** 실제 게재를 시작할 때 별도로 판단한다
- **동의 배너·CMP 를 만들지 마라.** 요청 범위 밖이다
- 레이아웃·스타일·다른 스크립트를 건드리지 마라

## 어디에

- `public/index.html` 의 `<head>`
- ⚠️ **`<head>` 를 가진 HTML 이 더 있는지 먼저 확인해라.** 있으면 **어디에 넣었고 왜 그 범위인지 보고에 적어라.** 임의로 전부에 넣지 말고, **사용자에게 보이는 공개 페이지**만
- 🔴 **`routes/pages.js` 가 `index.html` 에 본문을 주입한다**(SSR). 주입 로직이 `<head>` 를 문자열로 다루고 있으면 **깨질 수 있다.** 넣고 나서 SSR 본문이 그대로 나오는지 확인해라

## 반드시 같이 볼 것

1. **테스트** — `/login`·`/signup`·`/dashboard` 가 「본문이 비어 있음」으로 고정된 테스트가 있다(2026-09-08). **깨지면 안 된다**
2. **첫 화면 무게** — 2026-09-09 에 1,046KB → 8.4KB 로 줄인 자산이다. 이 스크립트는 외부에서 받아오므로 **우리 바이트는 거의 안 늘지만**, 브라우저가 받는 총량은 는다.
   **넣기 전/후로 홈 HTML 바이트를 재서 보고해라**(외부 스크립트 다운로드까지 잴 필요는 없다)
3. **`configs/privacyPolicy.js`** — 애드센스는 쿠키를 쓴다. **지금 개인정보 처리방침에 광고·쿠키 문구가 있는지 «확인만» 하고 보고해라. 고치지는 마라** — 문구는 Jay 가 정할 문제다

## 완료 조건

1. `npm test` 전부 통과
2. 로컬에서 서버를 띄워 **홈 HTML 에 스크립트 태그가 실제로 들어 있는지** 확인(문자열 검색)
3. **SSR 본문이 여전히 나오는지** 확인 — 홈·`/docs`·`/blog`
4. **인증 페이지 셋은 여전히 비어 있는지** 확인
5. 커밋 하나. 메시지에 **「승인용 로더만, 광고 단위 없음」**이 드러나게

## 보고에 적을 것

- 커밋 해시
- **어느 파일 어디에 넣었는지**, `<head>` 가 여럿이면 왜 그 범위인지
- 홈 HTML 바이트 전/후
- 개인정보 처리방침에 광고·쿠키 문구가 **있는지 없는지** (고치지 말고 사실만)
- 범위 밖이라 안 건드렸지만 발견한 것
