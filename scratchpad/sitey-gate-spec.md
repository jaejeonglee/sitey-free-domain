# 작업 — 생성 시 도달성 검사를 「거절」에서 「기록」으로

2026-09-14. 지시자: 자비스. **배포하지 마라 · 원격에 올리지 마라.** 로컬 커밋까지만. 자비스가 확인 후 반영한다.

## 왜

`routes/domain.js:255`(생성)와 `:352`(수정)이 A·CNAME 의 **대상이 HTTP 로 응답하지 않으면 400 `VALIDATION_UNREACHABLE` 로 거절**한다.

그래서 **「주소를 먼저 받고 그다음 배포하는」 흐름이 불가능하다.** 에이전트가 정확히 그 흐름이다.
sitey 를 MCP 목록에 등재하려는 참인데, 지금 등재하면 **문을 잠가놓고 광고하는 셈**이다.

**근거 숫자**(2026-09-07~09-14 서버 로그): 고유 방문 201(93%가 봇) · 첫 화면 1,677 · 이름 검색 65 · **발급 시도 2**.
막힌 곳은 기능이 아니라 유입이고, 그 유입을 열려는데 **문턱이 먼저 걸려 있다.**

## 핵심 — 검사를 «없애지» 마라

이 검사는 이유가 있어서 있다(빈 이름 선점 방지). 없애는 게 아니라 **판정 결과를 바꾼다.**

> **검사는 그대로 돌린다. 결과를 «거절»이 아니라 «기록»으로 쓴다.**

이미 이 일을 하는 장치가 있다 — 야간 도달성 점검이 **「N일째 안 열립니다」 안내 메일**을 보내고,
**삭제는 하지 않는다**(2026-09-08 Jay 결정: 도달성으로는 지우지 않는다. 삭제는 갱신 미이행으로만).
그리고 만료가 있다 — 계정 3개월 · 계정 없이 만든 것 1개월. **버려진 이름은 만료가 회수한다.**

즉 생성 시 거절은 **만료·한도와 겹치는 세 번째 자물쇠**이고, 그 자물쇠만 선의의 사용자를 막고 있다.

## 할 일

### 1. 생성(`routes/domain.js:255` 부근)

- 검사는 **그대로 실행**한다. 결과를 버리지 마라
- 응답을 **400 거절 → 생성 성공**으로 바꾼다
- 생성 결과에 **「지금은 아무것도 응답하지 않는다」**를 담아 호출자가 알 수 있게 한다.
  ⚠️ **기존 성공 응답의 모양을 깨지 마라.** 필드를 **더하는** 쪽으로. 기존 클라이언트가 깨지면 안 된다
- 구조화 로그에 판정을 남긴다. **어떤 이유로 안 열렸는지**까지(기존 `probeRecord` 의 `check`·`status`·`detail` 을 그대로 쓴다)

### 2. 수정(`routes/domain.js:352` 부근)

같은 처리를 한다. **생성은 되는데 수정은 거절당하면 더 이상하다.**

### 3. TXT 는 건드리지 마라

`services/validation.js:26` 이 A·CNAME 에만 probe 를 건다. **TXT 는 원래 검사 대상이 아니다.**
실사용 100%가 TXT(Vercel 인증)이므로 **그 경로에 어떤 변화도 생기면 안 된다.**

### 4. 발견 문서 3종이 따라와야 한다

`services/discovery.js` 가 **오류 코드 목록을 문서에 싣는다.** 생성에서 `VALIDATION_UNREACHABLE` 가 사라지면
`tests/discovery.test.js` 가 **양방향 대조에서 깨질 것**이다. 그게 정상이다 — **문서를 실제와 맞춰라.**

그리고 `llms.txt`·`openapi.json` 의 설명이 「가리킬 곳이 살아 있어야 한다」는 취지로 쓰여 있으면 **지금 동작으로 고쳐라.**
📌 이 문서들은 **설정에서 생성된다.** 문자열을 하드코딩하지 마라.

## 하지 말 것

- **배포·원격 업로드 금지.** 서버·DNS·DB 를 건드리지 마라
- **`services/validation.js` 의 probe 자체를 삭제하지 마라.** 야간 점검·안내 메일이 같은 함수를 쓴다
- **야간 점검의 «삭제하지 않는다» 정책을 건드리지 마라**(2026-09-08 결정)
- 한도·만료·결제 로직에 손대지 마라. 범위 밖이다
- 「하는 김에」 리팩터링 금지

1. `npm test` 전부 통과. **새 테스트는 고치기 전 코드에서 실패하는 것을 먼저 확인**하고 넣는다

   · 야간 점검이 그 레코드를 여전히 **안 열림으로 집어낸다**(안내 메일 경로가 산다)
3. 발견 문서 3종이 **지금 동작과 일치**한다(오류 코드 목록 포함). 하드코딩 없음
